# דמו שיעור 03 – לולאת ReAct

אותה הודעה פעמיים: פעם בלי לולאה, פעם עם ReAct (Thought → Action → Observation).
רואים את התשובה, את הפרומפט שנשלח, ואת מה שקרה מאחורי הקלעים.

משפט עוגן:

> **המודל בוחר את הצעד. הקוד מריץ. Observation חוזרת. זו לולאת ReAct.**

חיבור לשיעור 01: שם Function Calling היה ב-API. כאן אותה לולאה כתובה **בפרומפט**.

---

## הרצה

```bash
cd demos/03-react-loop
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

שימי מפתח ב-`.env`, ואז לחיצה כפולה על `הרצה.bat` או:

```bash
python app.py
```

בחלון: כותבות הודעה (או לוחצות על דוגמה) → בוחרות **בלי לולאה** או **עם ReAct** → **שלחי**.

מתחת לתיבה יש שלוש דוגמאות מ-`prompt.py`: חיוב כפול, החזר בלי בדיקה, ומחוץ לתחום.

אם OpenAI חסום (רימון), הקוד עובר לבד להדגמה מקומית או ל-Gemini. פירוט ב-`.env.example`.

## הקבצים להראות בכיתה (בסדר הזה)

| קובץ | מה יש בו |
|------|----------|
| `prompt.py` | הפרומפט: Role + Thought/Action + Few-Shot |
| `tools.py` | `lookup_bill` ו-`lookup_policy`. המודל לא נכנס לכאן |
| `ask_the_model.py` | השליחה למודל: בלי לולאה / עם ReAct (עד 4 צעדים) |
| `app.py` | החלון: הודעה, תשובה, פרומפט, מה קרה |

`llm_client.py` הוא חיבור טכני (OpenAI / Gemini / הדגמה מקומית). לא חובה לפתוח בכיתה.

---

## מה להגיד בכל מצב של ה-Radio

1. **בלי לולאה** – אותה הודעה. ממציא החזר או מתנצל. בפרומפט אין Thought ואין Action. ב«מה קרה» אין Observation.
2. **`prompt.py`** – Thought זה CoT. Action + Observation זו הלולאה. תיאור הפעולות הוא חלק מהפרומפט.
3. **עם ReAct** – ב«מה קרה» רואים: בקשה של המודל → הרצה שלנו → Observation → תשובה. הסכום 39.90 מגיע מ-`tools.py`, לא מהזיכרון.
4. **החזר בלי בדיקה** – עם ReAct עדיין שולפים חיוב ומדיניות. לא מתעלמים מהכללים.
5. **מזג אוויר** – עם ReAct המודל יכול `finish` בלי כלי. הוא מחליט *האם*, לא רק *איזה*.

## שרשרת (בקול, בלי קוד נוסף)

אם **הקוד** היה תמיד מריץ: חיוב → מדיניות → מייל – זו **שרשרת** (Workflow).  
כאן **המודל** בוחר את הסדר – זה **Agent**. נרחיב בשיעור 8.
