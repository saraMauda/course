# דמו שיעור 06 – Skills

אותה בקשה פעמיים: פעם בלי Skills (המודל לבד), פעם עם Skills (קטלוג → `activate_skill` → הנחיות מומחה).
רואים את התשובה, את הפרומפט שנשלח, ואת מה שקרה מאחורי הקלעים – כולל כמה תווים נטענו בכל שלב.

משפט עוגן:

> **אין קסם. Skill הוא קטלוג שמוגש למודל, ו-Tool שמחזיר הנחיות.**

חיבור לשיעור 01: `activate_skill` הוא Function Calling רגיל. המודל מבקש, **אנחנו** מריצות.
חיבור לשיעור 05: שם הזרקנו *ידע* לפרומפט. כאן מזריקות *נוהל עבודה* – ורק כשצריך.

## הרצה

```bash
cd demos/06-skills
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

שימי מפתח ב-`.env`, ואז לחיצה כפולה על `הרצה.bat` או:

```bash
python app.py
```

בחלון: כותבות בקשה (או לוחצות על דוגמה) → בוחרות **בלי Skills** או **עם Skills** → **שלחי**.

מתחת לתיבה יש שלוש דוגמאות מ-`prompt.py`: תלונה, סיכום מדיניות, ושאלה לא קשורה.

אם OpenAI חסום (רימון), הקוד עובר לבד להדגמה מקומית או ל-Gemini. פירוט ב-`.env.example`.

## הקבצים להראות בכיתה (בסדר הזה)

| קובץ | מה יש בו |
|------|----------|
| `skills/complaint-reply/SKILL.md` | skill אמיתי: frontmatter (name, description) + נוהל + Checklist |
| `skills.py` | **Discovery**: סריקת התיקייה, חילוץ name / description / body, `catalog()` |
| `prompt.py` | הכלי `activate_skill`. הקטלוג נמצא **בתוך התיאור שלו** |
| `ask_the_model.py` | הלולאה: קטלוג → בקשת המודל → טעינת body → תשובה |
| `app.py` | החלון: בקשה, תשובה, מה נשלח, מה קרה |

`llm_client.py` הוא חיבור טכני (OpenAI / Gemini / הדגמה מקומית). לא חובה לפתוח בכיתה.

> בדמו יש שלוש שכבות של Progressive Disclosure, אבל רק שתיים רצות בקוד: Metadata ו-SKILL.md. את השכבה השלישית (`scripts/`, `references/`, `assets/`) מסבירים בקול.

## מה להגיד בכל מצב של ה-Radio

1. **בלי Skills** – «תכתבי תשובה ללקוחה כועסת». המודל כותב תשובה נחמדה, ומבטיח «כל הכסף מיד» ו«פיצוי». הוא לא מכיר את הנהלים. ב«מה נשלח»: אין קטלוג.
2. **`SKILL.md`** – זה הנוהל: ארבעה חלקים, כללים, Checklist. לשון ציווי, תמציתי.
3. **`skills.py`** – Discovery. **האפליקציה** מגלה, לא המודל. הוא לא יודע שהתיקייה קיימת.
4. **עם Skills** – ב«מה קרה» רואים: שלב 1 (name + description בלבד) → המודל בוחר → שלב 2 (טוענים body של skill אחד). ה-body של שני האחרים לא נשלח.
5. **תשובה** – ארבעה חלקים, «5 ימי עסקים», בלי פיצוי. אותו מודל, אחרי שקיבל נוהל.
6. **סיכום מדיניות** – skill אחר נבחר, לפי ה-description.
7. **בירת צרפת** – אף skill לא מתאים. המודל לא מפעיל כלום. «Skill לא נטען סתם».
