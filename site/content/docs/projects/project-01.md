- שרשרת סיווג כוונה → תשובה (שיעור 3)
- השוואת ערכי סף שונים ותיעוד ההשפעה

> הצגת top-K מקורות + ציון דמיון, ושדה `out_of_scope`, כלולים כבר בגרסת הבסיס.

## ⚙️ תהליך המימוש

### עיקרון
- embedding לשאלות בלבד; תשובות במפה נפרדת
- שאילתה חדשה → וקטור → שכנים → תשובות → פרומפט → LLM

### שלב 1 – Dataset
תחום ממוקד (למשל שירות סלולר). עשרות זוגות `question` / `answer`.

### שלב 2 – Embeddings
אותו מודל לכל האינדקס והשאילתות.

### שלב 3 – שמירת וקטורים
נרמול הווקטורים ושמירה ל-`.npy`. הדמיון = מכפלה פנימית (cosine).

### שלב 4 – Runtime retrieval
N = 3–5 שכנים. **סף דמיון:** מתחתיו לא קוראים ל-LLM ומחזירים out_of_scope. הסף נקבע לפי ציונים שמודדים, לא ניחוש.

### שלב 5 – Prompt + LLM
תבנית Guardrails (ראו שיעור 5) + מבנה פלט מוסכם.

### שלב 6 – Gradio UI
קלט שאלה → תשובה (+ מקורות).
