## המטרה

חלון Gradio שבו כותבות הודעת לקוח ורואות:

1. תשובה
2. מה נשלח למודל (הפרומפט)
3. מה קרה מאחורי הקלעים

פעם **בלי מבנה**, פעם **עם Analyzer**.

שדות ה-JSON החדשים:

```json
{
  "intent": "order|hours|other",
  "in_scope": true,
  "answer": "משפט קצר"
}
```

## שלב 1 — `prompt.py`

שלושה שינויים. תשאירי את שאר הקובץ כמו שהוא.

**א. הפרומפט** — החליפי את `SYSTEM_PROMPT` בזה:

```python
SYSTEM_PROMPT = """
את מסווגת הודעות לקוח למסעדה.

Role: את עוזרת של מסעדה. מסווגת כוונה ועונה קצר.

Guardrails:
- עני ב-JSON בלבד. בלי markdown, בלי הסברים מחוץ ל-JSON.
- intent רק order, hours או other.
- in_scope הוא true רק להזמנה או לשעות פתיחה.
- אם in_scope הוא false – אל תמציאי תפריט, מחירים או שעות. ב-answer הסבירי שזה מחוץ לתחום.
- answer משפט קצר בעברית.

Few-Shot:
קלט: "אפשר שתי פיצות משפחתיות?"
פלט: {"intent":"order","in_scope":true,"answer":"כן, אפשר להזמין. איזה תוספות?"}

קלט: "עד מתי אתם פתוחים?"
פלט: {"intent":"hours","in_scope":true,"answer":"אנחנו פתוחים עד 23:00."}

קלט: "מה מזג האוויר מחר?"
פלט: {"intent":"other","in_scope":false,"answer":"אני עוזרת רק בהזמנות ובשעות פתיחה."}

עני ב-JSON בלבד במבנה:
{
  "intent": "order|hours|other",
  "in_scope": true/false,
  "answer": "משפט קצר"
}
""".strip()
```

**ב. השאלה בלי מבנה, ודוגמאות:**

| חפשי | החליפי ל- |
|------|-----------|
| `האם הטקסט הבא בעייתי?` | `מה הלקוח רוצה בהודעה הבאה?` |

החליפי את רשימת `EXAMPLES` בזה (הזמנה, שעות, ומחוץ לתחום):

```python
EXAMPLES = [
    "אפשר להזמין פיצה?",
    "עד מתי אתם פתוחים?",
    "מה מזג האוויר?",
]
EXAMPLE_TEXT = EXAMPLES[0]
```

## שלב 2 — `schema.py`

מחקי את מחלקת `AnalyzerResult`, והדביקי **בדיוק** את זה במקומה:

```python
class IntentResult(BaseModel):
    intent: Literal["order", "hours", "other"]
    in_scope: bool
    answer: str
```

שימי לב לשלושה דברים בלבד:

| בדמו של השיעור | אצלך |
|----------------|------|
| `violation` / `category` / `riskLevel` / `manipulative` | `intent` / `in_scope` / `answer` |
| `AnalyzerResult` | `IntentResult` |
| מדיניות סינון | כוונת לקוח במסעדה |

**חובה:** בתוך `parse_output` החליפי גם את שם המחלקה:

| חפשי | החליפי ל- |
|------|-----------|
| `AnalyzerResult.model_validate` | `IntentResult.model_validate` |

## איך בודקות שהצלחת

הרצי `python app.py` מתוך התיקייה החדשה.

| # | טקסט | מצב | מה חייבים לראות |
|---|------|------|------------------|
| 1 | אפשר להזמין פיצה? | בלי מבנה | תשובה חופשית. ב«מה נשלח» אין JSON ואין Role. ב«מה קרה» כתוב: אין ולידציה. |
| 2 | אפשר להזמין פיצה? | עם Analyzer | JSON תקין. `intent` הוא `order`. ב«מה קרה» כתוב שה-JSON תקין והוולידציה עברה. |
| 3 | מה מזג האוויר? | עם Analyzer | `in_scope` הוא `false`. ב-`answer` אין תפריט מומצא ואין מחירים. |

אם בדיקה 2 מחזירה טקסט חופשי במקום JSON — חזרי ל-`SYSTEM_PROMPT`. חסרה שם ההוראה «עני ב-JSON בלבד».
