## שלב 1 — `tools.py`

מחקי את התוכן, והדביקי **בדיוק** את זה:

```python
# הכלים של ספרייה עירונית.
# כאן אנחנו מריצות אותם בעצמנו ב-tools node.

import json
import re

from langchain.tools import tool

ACCOUNTS = {
    "205": {"customer": "205", "note": "קנס איחור של 12 ₪ על הספר «הנסיך הקטן», 12 ימי איחור."},
    "300": {"customer": "300", "note": "אין קנסות פתוחים."},
}

KNOWLEDGE = [
    {"id": "late-fee", "text": "איחור: קנס של 1 ₪ ליום איחור, עד תקרה של 30 ₪. ביטול קנס רק אחרי אימות מול הדלפק."},
    {"id": "loan", "text": "השאלה: 21 יום, עד 5 ספרים. הארכה אחת של 14 יום, באפליקציה."},
    {"id": "card", "text": "כרטיס מנוי: הנפקה בדלפק עם תעודה מזהה. כרטיס אבוד מוחלף תמורת 10 ₪."},
]


@tool
def get_account(customer_id: str) -> str:
    """מחזיר את הקנסות ופרטי המנוי לפי מספר מנוי. השתמשי כשהמנוי שואל על קנס ויש מספר מנוי."""
    key = customer_id.strip()
    data = ACCOUNTS.get(key, {"customer": key, "note": "המנוי לא במאגר."})
    return json.dumps(data, ensure_ascii=False)


@tool
def search_sources(query: str) -> str:
    """חיפוש במאגר הידע של הספרייה: איחורים, השאלות וכרטיסים. השתמשי כשצריך לדעת מה הנוהל. לא למידע על מנוי מסוים."""

    def words_of(text: str) -> set:
        return {w for w in re.findall(r"\w+", text) if len(w) > 2}

    words = words_of(query)
    scored = [(len(words & words_of(item["text"])), item) for item in KNOWLEDGE]
    scored.sort(key=lambda pair: pair[0], reverse=True)
    best = [item for score, item in scored[:2] if score > 0]
    if not best:
        return "לא נמצא במאגר."
    return " ".join(f"[{item['id']}] {item['text']}" for item in best)


TOOLS = [get_account, search_sources]
TOOLS_BY_NAME = {t.name: t for t in TOOLS}
```

שמות הכלים **נשארים** (`get_account`, `search_sources`). רק התוכן משתנה.

## שלב 3 — `graph.py`: שני החלקים שלך

מחקי את **הגוף** של שתי פונקציות (השאירי את החתימה) וכתבי אותן מחדש:

**א. `merge_unique(old, new)` — ה-Reducer של `sources`.**

| דרישה | פירוט |
|-------|--------|
| מחזירה רשימה | הישנה, ואחריה החדשים |
| בלי כפילויות | פריט שכבר ברשימה לא נוסף שוב |
| שומרת סדר | הפריטים הישנים נשארים בסדר שלהם |

**ב. `should_continue(state)` — הקשת המותנית.**

| דרישה | פירוט |
|-------|--------|
| ההודעה האחרונה ב-`state["messages"]` מבקשת כלי | מחזירה `"tools"` |
| אחרת | מחזירה `END` |

רמז: `tool_calls` נמצא על ההודעה האחרונה. השתמשי ב-`getattr(last, "tool_calls", None)`.

אל תשני שום דבר אחר ב-`graph.py`.
