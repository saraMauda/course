## שלב 1 — `tools.py`

מחקי את התוכן, והדביקי **בדיוק** את זה:

```python
# הפעולות בעולם האמיתי.
# המודל לעולם לא נכנס לכאן. הוא רק מבקש שנריץ.

import json

ORDERS = {
    "88": {
        "order_id": "88",
        "status": "במסירה",
        "city": "תל אביב",
        "eta": "היום עד 18:00",
    },
    "21": {
        "order_id": "21",
        "status": "הוכנה במחסן",
        "city": "חיפה",
        "eta": "מחר",
    },
}

SHIPPING = {
    "88": "שליח בדרך לתל אביב. אפשר ליצור קשר עד 18:00.",
    "21": "החבילה במחסן. תצא מחר בבוקר.",
}


def lookup_order(order_id: str) -> str:
    key = order_id.strip()
    data = ORDERS.get(key, {"order_id": key, "error": "ההזמנה לא במאגר"})
    return json.dumps(data, ensure_ascii=False)


def lookup_shipping(order_id: str) -> str:
    key = order_id.strip()
    info = SHIPPING.get(key, "לא נמצא מידע משלוח.")
    return json.dumps({"order_id": key, "shipping": info}, ensure_ascii=False)


def run_action(name: str, action_input: str) -> str:
    if name == "lookup_order":
        return lookup_order(action_input)
    if name == "lookup_shipping":
        return lookup_shipping(action_input)
    return json.dumps({"error": f"פעולה לא מוכרת: {name}"}, ensure_ascii=False)
```

שימי לב לשלושה דברים בלבד:

| בדמו של השיעור | אצלך |
|----------------|------|
| `lookup_bill` | `lookup_order` |
| `lookup_policy` | `lookup_shipping` |
| מילון חיובים | מילון הזמנות |

## שלב 2 — `prompt.py`

שלושה שינויים. תשאירי את שאר הקובץ כמו שהוא.

**א. הפרומפט** — החליפי את `SYSTEM_PROMPT` בזה:

```python
SYSTEM_PROMPT = """
את נציגת שירות של חנות אונליין.

Role: את עוזרת ללקוחה על הזמנות ומשלוחים. חושבת בקול, ואז בוחרת פעולה אחת.

Guardrails:
- אל תמציאי סטטוס, עיר או זמן הגעה.
- אם חסר נתון – בקשי פעולה, אל תנחשי.
- פעולה אחת בכל תור. רק מהרשימה.
- עני בדיוק במבנה Thought / Action / ActionInput. בלי markdown.

פעולות:
- lookup_order — סטטוס הזמנה לפי מספר
- lookup_shipping — פרטי משלוח לפי מספר הזמנה
- finish — תשובה סופית ללקוחה (רק כשיש מספיק מידע)

Few-Shot:
שאלה: איפה הזמנה 88?
Thought: צריך את סטטוס ההזמנה לפני תשובה.
Action: lookup_order
ActionInput: 88

שאלה: מה מזג האוויר?
Thought: זה לא נושא של הזמנות. אין מה לשלוף.
Action: finish
ActionInput: אני עוזרת רק בהזמנות ובמשלוחים, לא במזג אוויר.

עני תמיד כך:
Thought: משפט קצר
Action: lookup_order או lookup_shipping או finish
ActionInput: הפרמטר או התשובה הסופית
""".strip()
```

**ב. השאלה בלי לולאה, הפעולות, והדוגמאות:**

| חפשי | החליפי ל- |
|------|-----------|
| `אין לך גישה לחיובים או למדיניות.` | `אין לך גישה להזמנות או למשלוחים.` |
| `ACTIONS = ("lookup_bill", "lookup_policy", "finish")` | `ACTIONS = ("lookup_order", "lookup_shipping", "finish")` |

## איך בודקות שהצלחת

הרצי `python app.py` מתוך התיקייה החדשה.

| # | הודעה | מצב | מה חייבים לראות |
|---|------|------|------------------|
| 1 | איפה הזמנה 88? | בלי לולאה | תשובה חופשית. ב«מה נשלח» אין Thought ואין Action. ב«מה קרה» אין הרצת `lookup_order`. |
| 2 | איפה הזמנה 88? | עם ReAct | ב«מה קרה» יש `lookup_order`. התוצאה מהקוד כוללת `"status": "במסירה"`. |
| 3 | מה מזג האוויר? | עם ReAct | `Action: finish` בלי `lookup_order`. אין מספר מעקב מומצא. |

אם בדיקה 2 לא מפעילה `lookup_order` — חזרי ל-`SYSTEM_PROMPT`. חסרות שם הפעולות או המבנה Thought / Action.
