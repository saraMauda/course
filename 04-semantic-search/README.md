# דמו שיעור 04 – חיפוש סמנטי

אותה שאילתה פעמיים: פעם בחיפוש מילולי, פעם בחיפוש סמנטי (embedding + Cosine).
רואים את התשובה מהמאגר, מה הוטמע / מה חיפשו, ואת מה שקרה מאחורי הקלעים.

משפט עוגן:

> **Cosine מסתכל על הזווית — לאן מצביעים — לא על כמה ארוך הוקטור.**

זה עדיין לא RAG: אין הזרקה לפרומפט ואין Generation. בשיעור 05 מחברים את האחזור לתשובת מודל.

---

## הרצה

```bash
cd demos/04-semantic-search
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

שימי מפתח ב-`.env`, ואז לחיצה כפולה על `הרצה.bat` או:

```bash
python app.py
```

בחלון: כותבות שאילתה (או לוחצות על דוגמה) → בוחרות **חיפוש מילולי** או **חיפוש סמנטי** → **שלחי**.

מתחת לתיבה יש שלוש דוגמאות מ-`catalog.py`: ניסוח אחר, מילה משותפת, ומזג אוויר.

אם OpenAI חסום (רימון), הקוד עובר לבד להדגמה מקומית או ל-Gemini. פירוט ב-`.env.example`.

## הקבצים להראות בכיתה (בסדר הזה)

| קובץ | מה יש בו |
|------|----------|
| `catalog.py` | מאגר Q&A קטן + שלוש דוגמאות לחלון |
| `search.py` | `keyword_search` ו-`semantic_search` (cosine בזיכרון) |
| `ask_the_model.py` | מילולי / סמנטי, מחזיר תשובה + מה הוטמע + מה קרה |
| `app.py` | החלון: שאילתה, תשובה, מה הוטמע, מה קרה |

`llm_client.py` הוא חיבור טכני (OpenAI / Gemini / הדגמה מקומית + `embed`). לא חובה לפתוח בכיתה.

## מה להגיד בכל מצב של ה-Radio

1. **חיפוש מילולי** – «נגמר לי האינטרנט…». לא מוצא את «חבילת גלישה». בוט תמיכה שנשען על מילים מדויקות נכשל כאן. ב«מה חיפשו» אין embedding.
2. **`catalog.py`** – זה המאגר. השאילתה בניסוח אחר, הפריט במאגר במילים אחרות. אין Vector DB – רשימה בזיכרון.
3. **חיפוש סמנטי** – אותה שאילתה. ב«מה קרה» רואים ציון cosine. נבחר הפריט על **זווית**, לא על מחרוזת. אותו מודל embedding לשאילתה ולמאגר.
4. **מילה משותפת** – «חיוב כפול על חבילת גלישה». גם מילולי יכול למצוא, כי יש מילים זהות במאגר.
5. **מזג אוויר** – בסמנטי הציון נמוך מהסף. «לא מצאתי מקור מספיק קרוב». לא ממציאים חבילת גלישה.
