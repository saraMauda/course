Function Calling – הזרימה

User
שאלה
←
Bot / Host
מגדיר כלים, מריץ
←
Model
בוחר / מנסח
←
כלי בעולם
get_weather
  1. משתמש שולח Query. הכלים רק מוגדרים, עדיין לא רצו.
  2. Bot שולח למודל: השאלה + רשימת הכלים. המודל מחליט האם ואיזה.
  3. חוזר Tool Call – שם + פרמטרים. הקוד שלנו מריץ – לא המודל.
  4. מחזירים למודל את התוצאה האמיתית.
  5. המודל מנסח תשובה אנושית.
  6. התשובה חוזרת למשתמש.
משפט עוגן: ה-LLM לא מריץ את הפונקציה. הוא בוחר מה להריץ. אנחנו מריצות.

הדמו – אותה שאלה, שני עולמות

שאלה: מה הטמפרטורה בתל אביב עכשיו?

בלי כלים → ממציא או מתנצל. רואים את הפרומפט בלי כלים.
עם כלי get_weather → המודל מבקש, אנחנו מריצות, הוא מנסח.
בחלון רואים: תשובה, מה נשלח למודל, ומה קרה מאחורי הקלעים.
