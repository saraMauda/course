# דמו שיעור 05 – RAG

אותה שאלה פעמיים: פעם בלי RAG (המודל לבד), פעם עם RAG (אחזור → פרומפט מועשר → תשובה).
רואים את התשובה, את הפרומפט שנשלח, ואת מה שקרה מאחורי הקלעים.

משפט עוגן:

> **RAG = המודל לא יודע. אנחנו מביאות לו את המקור, ו-Guardrails מחזיקים אותו בתוכו.**

חיבור לשיעור 04: שם עצרנו באחזור – מצאנו מקטע או שלא. כאן מזריקות אותו לפרומפט ומוסיפות Generation.

---

## הרצה

```bash
cd demos/05-rag
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

שימי מפתח ב-`.env`, ואז לחיצה כפולה על `הרצה.bat` או:

```bash
python app.py
```

בחלון: כותבות שאלה (או לוחצות על דוגמה) → בוחרות **בלי RAG** או **עם RAG** → **שלחי**.

מתחת לתיבה יש שלוש דוגמאות מ-`catalog.py`: ניסוח אחר, שאלת מדיניות, ומחוץ לתחום.

אם OpenAI חסום (רימון), הקוד עובר לבד להדגמה מקומית או ל-Gemini. פירוט ב-`.env.example`.

---

## הקבצים להראות בכיתה (בסדר הזה)

| קובץ | מה יש בו |
|------|----------|
| `catalog.py` | הידע של החברה: Q&A סלולר + שלוש דוגמאות לחלון |
| `search.py` | Offline: `build_index` (embedding רק לשאלות). Runtime: `retrieve` (cosine, top-K) |
| `prompt.py` | תבנית ה-Augment: הקשר + שאלה + Guardrails |
| `ask_the_model.py` | בלי RAG: שאלה לבד. עם RAG: אחזור → פרומפט → מודל |
| `app.py` | החלון: שאלה, תשובה, מה נשלח, מה קרה |

`llm_client.py` הוא חיבור טכני (OpenAI / Gemini / הדגמה מקומית + `embed`). לא חובה לפתוח בכיתה.

> בדמו האחזור הוא cosine בזיכרון, כמו בשיעור 04. שמירת הווקטורים ב-`.npy` נכנסת בפרויקט 1.

## מה להגיד בכל מצב של ה-Radio

1. **בלי RAG** – «נגמר לי האינטרנט…». המודל עונה בביטחון, בלי מקור. אין הקשר בפרומפט. ב«מה קרה» כתוב: אין מקור, אין ציון.
2. **`prompt.py`** – זה ה-Augmented. ההקשר נכנס לפרומפט, והמשפט «רק מההקשר» הוא ה-Guardrail.
3. **עם RAG** – אותה שאלה. ב«מה קרה» רואים: אחזור → ציון cosine → מקור נכנס לפרומפט → תשובה מהמאגר. הקוד לא נגע במודל, רק בנה לו פרומפט.
4. **שאלת מדיניות** – «חויבתי פעמיים». בלי RAG המודל ממציא «החזר מלא מיד». עם RAG: «החזר של חיוב אחד תוך 5 ימי עסקים». הפרט הזה קיים רק במאגר.
5. **מזג אוויר** – אף מקור לא עובר את הסף. הפרומפט נשלח בכל זאת, וה-Guardrail גורם למודל לומר «אין מספיק מידע». לא ממציאים.

## מה מפרידים בקול

- **Offline** – `build_index`: פעם אחת, לפני שמישהי שואלת.
- **Runtime** – `retrieve` + `build_prompt` + המודל: בכל שאלה.
