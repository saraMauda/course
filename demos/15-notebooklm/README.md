# דמו שיעור 15 – מחברת קטנה מקצה לקצה (NotebookLM Deep Dive)

כל הקורס בחלון אחד: מקורות שעוברים **אישור אנושי**, נחתכים ומאונדקסים ב-`SourceStore`, ושיחה בגרף LangGraph עם אחזור, ציטוטים, כלי חיצוני וזיכרון.
זה **שלד קטן** של פרויקט 3: פרוסה אנכית שעובדת, שאפשר להרחיב.

משפט עוגן:

> **מודל לבד לא מספיק. הקשר (RAG), כלים, בקרה (HITL), גרף וזיכרון הופכים אותו למערכת.**

חיבור לכל השיעורים: טבלת «מפת הקורס» נמצאת בחלון (תפריט נפתח) ובקובץ `prompt.py`.

## הרצה

```bash
cd demos/15-notebooklm
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

שימי מפתח ב-`.env`, ואז לחיצה כפולה על `הרצה.bat` או:

```bash
python app.py
```

בחלון: **העלי 4 מקורות** → מסמנות מה לאשר → **אשרי** → שואלות שאלה. **מחברת חדשה** מאפסת אינדקס ו-`thread_id`.

אם OpenAI חסום (רימון), הקוד עובר לבד להדגמה מקומית או ל-Gemini. פירוט ב-`.env.example`.

> **שימי לב:** בהדגמה המקומית (mock) ההטמעה היא **מילולית** (שק מילים), לא סמנטית, והתשובה מצטטת את המקטעים הכי קרובים. עם מודל אמיתי האחזור סמנטי, והציונים והניסוחים ישתנו. החיפוש ברשת הוא stub. ה-API של LangGraph מתעדכן. אם יש שגיאת import, בדקי ב-docs.

## הארכיטקטורה (ובאיזה קובץ כל חלק)

```text
UI (app.py)
 ├─ Source Pipeline:  hitl.py  parse → [interrupt: אישור] → index ──► source_store.py (chunk, embed, search)
 └─ Chat Graph:       graph.py  retrieve → agent ↔ tools(web_search) → END   + checkpointer
                      chat.py   הדלת: upload / approve / ask, thread_id, ציטוטים, trace מקומי
```

| קובץ | מה יש בו |
|------|----------|
| `prompt.py` | המקורות, `NOTEBOOK_SYSTEM` (ציטוט, סירוב, סתירה, הפרדה), ומפת הקורס |
| `source_store.py` | `chunk_text`, `SourceStore.add_source`, `search` עם `TOP_K` ו-`MIN_SCORE` |
| `hitl.py` | גרף ה-ingest: `parse`, `await_approval` (`interrupt`), `index` |
| `graph.py` | `NotebookState`, `retrieve`, `agent`, `tools`, `should_continue`, `build_chat` |
| `tools.py` | `web_search` (stub) |
| `chat.py` | `upload`, `approve`, `ask`: מעביר `thread_id`, מוציא ציטוטים |
| `app.py` | החלון |

`llm_client.py` הוא חיבור טכני (מודל, הטמעה, ומצב מקומי). לא חובה לפתוח בכיתה.

## סדר הקריאה בכיתה (Code Walkthrough)

1. `NotebookState` ב-`graph.py`: `messages`, `question`, `web`, `chunks`.
2. `SourceStore.add_source` ו-`search`: חיתוך, הטמעה, cosine, סף.
3. nodes: `retrieve`, `agent`, `tools`, והקשת המותנית.
4. `build_chat`: compile עם checkpointer.
5. `chat.py` והחלון: upload → approve → chat.

## שלושת תרחישי ה-runtime (מה להראות)

1. **שאלה מכוסה במקור.** מאשרות רק S1, S2, S3. «איפה אפשר לראות את החיובים שלי?». ב«מה קרה»: `retrieve` שלף מקטע אחד עם ציון, והתשובה מסתיימת בציטוט `[S2]` וב«ציטוטים: S2 — מדריך חיוב». «אין ציטוט, אין אמון.»
2. **שאלה מחוץ למקורות.** «מה מזג האוויר?». לא נשלף כלום מעל הסף ← «אין מספיק מידע במקורות שאושרו». אותה שאלה עם **הרחבה לאינטרנט**: `agent` ביקש `web_search`, והתשובה מסומנת «מהרשת (לא מהמקורות שלך)». «המודל החליט לחפש, ו**מסמן** מאיפה המידע.»
3. **מקור שנדחה ב-HITL לא מופיע.** «מה המדיניות על חיוב כפול?» בשתי הרצות:
   - **מאשרות הכל:** נשלפים S1 ו-**S4** (התקנון הישן מ-2019), והתשובה מצטטת **שניהם, ויש סתירה** (5 ימי עסקים מול 30 ימים).
   - **דוחות את S4:** נשלף רק S1. S4 לא באינדקס, ולכן אי אפשר לשלוף אותו.
   «זו הסיבה שיש שלב אישור: אדם רואה מה נכנס.» ב-UI S4 מסומן ⚠️ «ייתכן לא עדכני».

## זיכרון

אחרי כמה שאלות, בשורה התחתונה: `thread_id` ומספר ההודעות השמורות גדל. «אותו `thread_id` = אותה מחברת.» **מחברת חדשה** פותחת `thread_id` חדש ומאפסת את האינדקס.

> מגבלה מכוונת בדמו: `retrieve` מוסיף להיסטוריה הודעה עם ההקשר המלא בכל תור, ולכן ההיסטוריה מתנפחת (Context Rot, שיעור 10). בפרויקט 3 כדאי לשמור בהיסטוריה רק את השאלה, ולהזריק הקשר רק לקריאה הנוכחית.

## מה לא בדמו (בקול)

- **LangSmith:** «מה קרה בגרף» הוא trace מקומי. בפרויקט 3 מחברות project אמיתי ושומרות לפחות traces.
- **MCP, Skill, Multi-agent fan-out, Pydantic structured answer:** בונוסים של פרויקט 3.
- **Evals:** אותו dataset ושני מדדים משיעור 14 (אחזור + תשובה), על המחברת שלך.
- **PDF / URL / chunking מתקדם:** כאן 4 מקורות טקסט קבועים, ומקטע = משפט.

## שאלות לדיון

- מה קורה אם מדלגים על HITL ומאנדקסים הכל אוטומטית? ← סתירות (S4), מקורות לא רלוונטיים, ותוכן זדוני (שיעור 13).
- למה `MIN_SCORE`? ← בלי סף תמיד נשלוף *משהו* ונענה בביטחון על שאלה שאין לה מקור. (שיעור 14: גרסה C.)
- למה קטן = דיוק ציטוט, גדול = הקשר? ← אסטרטגיית חיתוך היא פשרה. (שיעורי הבית.)
- איזו רגל מ«שלוש הרגליים» הורדנו כאן? ← אין Tool שולח לסוכן שקורא מקורות.
