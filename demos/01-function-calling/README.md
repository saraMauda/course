# דמו שיעור 01 – Function Calling

אותה שאלה פעמיים: פעם בלי כלים, פעם עם `get_weather`.
רואים את התשובה, את הפרומפט שנשלח, ואת מה שקרה מאחורי הקלעים.

משפט עוגן:

> **ה-LLM לא מריץ את הפונקציה. הוא בוחר מה להריץ. אנחנו מריצות.**

---

## הרצה

```bash
cd demos/01-function-calling
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

שימי מפתח ב-`.env`, ואז לחיצה כפולה על `הרצה.bat` או:

```bash
python app.py
```

בחלון: כותבות שאלה → בוחרות **בלי כלים** או **עם כלי** → **שלחי**.

אם OpenAI חסום (רימון), הקוד עובר לבד להדגמה מקומית או ל-Gemini. פירוט ב-`.env.example`.

---

## הקבצים להראות בכיתה (בסדר הזה)

| קובץ | מה יש בו |
|------|----------|
| `prompt.py` | הפרומפט + סכימת הכלי `get_weather` |
| `weather_tool.py` | הפונקציה בעולם. המודל לא נכנס לכאן |
| `ask_the_model.py` | השליחה למודל: בלי כלים / עם כלי (שתי קריאות) |
| `app.py` | החלון: שאלה, תשובה, פרומפט, מה קרה |

`llm_client.py` הוא חיבור טכני (OpenAI / Gemini / הדגמה מקומית). לא חובה לפתוח בכיתה.

---

## מה להראות על המסך

1. **בלי כלים** – אותה שאלה. ממציא או מתנצל. בפרומפט כתוב «לא נשלחו כלים».
2. **`prompt.py`** – התיאור של הכלי הוא חלק מהפרומפט.
3. **עם כלי** – ב«מה קרה» רואים: בקשה של המודל → הרצה שלנו → ניסוח תשובה.
4. בונוס קצר: «מה בירת צרפת?» עם כלי. המודל יכול לענות בלי להפעיל את `get_weather`.
