# דמו שיעור 11 – LangGraph: State, Nodes, Edges

בונות את אותו סוכן ReAct מאפס, **כגרף**, בשלושה שלבים. בכל שלב רואות את המסלול (`START → agent → tools → agent → END`), מה כל node כתב ל-State, ואת הגרף עצמו ב-Mermaid.

משפט עוגן:

> **אותו ReAct. רק שהזרימה כתובה, נראית, ושלנו.**

חיבור לשיעור 03: אותה לולאה (מודל → פעולה → Observation → מודל). שם בפרומפט, כאן בגרף.
חיבור לשיעור 08: שם הקוד שלט בנתיב. כאן הנתיב **מצויר**, ועדיין המודל מחליט (בקשת כלי = קשת מותנית).
חיבור לשיעור 09: `create_agent` בנוי על LangGraph. עכשיו פותחות את הקופסה.
חיבור לשיעור 10: `checkpointer` + `thread_id`, אותו דבר, רק על גרף שלנו.

## מה להגיד בכל שלב

אחרי כל שלב שואלות את הכיתה: **«מה כתוב ל-State עכשיו? מה ה-edge הבא?»** ולא מתקדמות בלי תשובה.

1. **שלב 1 – node יחיד.** `State` עם `messages` בלבד. שלושה `add_node`/`add_edge`: `START → agent → END`. בדוגמה על לקוח 312: תשובה בטוחה שמנחשת. «אין כלים, אין לולאה.» ב-Mermaid: שלוש קופסאות.
2. **שלב 2 – ReAct.** מוסיפות node `tools` ושתי קשתות: `agent → tools` **מותנית**, `tools → agent` קבועה. פתחי `should_continue`: «אם יש `tool_calls` → tools, אחרת END.» בדוגמת לקוח 312, ב«מה כל node כתב»: agent ביקש `get_account` → קשת מותנית → tools הריץ → חזרה ל-agent → קשת מותנית → END. **«זה בדיוק ReAct משיעור 3, רק מצויר.»** על «מזג אוויר»: `START → agent → END`, הקשת המותנית הובילה ישר ליציאה.
3. **שלב 3 – State עשיר + זיכרון.** `State` עם `sources`, ו-`merge_unique`. ב-State בסוף: `sources: ['account:312']`. שולחות «מדיניות ביטול» באותה שיחה, ו-`sources` **גדל** (לא נדרס): `['account:312', 'cancel']`. «בלי Reducer, כל node היה דורס את הרשימה.» עם «שלום, שמי דנה» ואז «מה שמי?»: «קוראים לך דנה». `thread_id` שמור, `messages` גדל.
4. **Reducers** – `add_messages` ו-`merge_unique`: «Node מחזיר **רק** מה שהשתנה, והמיזוג נעשה על ידי ה-Reducer. מי שמחזירה State שלם בלי להבין – נשברת.»
5. **Mermaid** – מעתיקות את הטקסט ל-mermaid.live ורואות את הגרף. זה מה שנכנס ל-README של פרויקט 3.

## מה לא בדמו (בקול)

- **Fan-out / Fan-in** (כמה עובדים במקביל): שיעור 12.
- **עצירה לאישור אדם** (`interrupt`, breakpoints): שיעור 13.
- **Traces ו-Evals** של מסלול מדויק: LangSmith, שיעור 14.
- ב-`create_agent` אי אפשר להוסיף node משלך באמצע. בגרף כן.

## שאלות לדיון

- מתי `create_agent` מספיק, ומתי עוברות לגרף? ← כשצריך הסתעפויות, מקביליות, עצירה לאדם, State עשיר או דיבאג של מסלול.
- למה `should_continue` צריכה להישאר קצרה? ← לוגיקה עסקית גדולה בתוך קשת מותנית קשה לקריאה ולבדיקה.
- מה קורה אם node מחזיר את כל ה-State? ← עם Reducer הוא ימוזג (ויכפיל הודעות), בלי Reducer הוא ידרוס.
- מה `recursion_limit` עושה? ← תקרת צעדים. בגרף עם לולאה, בלי תקרה סוכן תקוע רץ לנצח.
