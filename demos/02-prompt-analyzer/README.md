# דמו שיעור 02 – Prompt Analyzer

אותו טקסט פעמיים: פעם בלי מבנה, פעם עם Analyzer (Role + Guardrails + Few-Shot + JSON).
רואים את התשובה, את הפרומפט שנשלח, ואת מה שקרה מאחורי הקלעים.

משפט עוגן:

> **בלי מבנה מקבלות טקסט. עם Analyzer מקבלות חוזה שהקוד יכול לבדוק.**

---

## הרצה

```bash
cd demos/02-prompt-analyzer
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

שימי מפתח ב-`.env`, ואז לחיצה כפולה על `הרצה.bat` או:

```bash
python app.py
```

בחלון: כותבות טקסט (או לוחצות על דוגמה) → בוחרות **בלי מבנה** או **עם Analyzer** → **שלחי**.

מתחת לתיבה יש שלוש דוגמאות מ-`prompt.py`: תמימה, פישינג, ומעטפת מניפולטיבית.

אם OpenAI חסום (רימון), הקוד עובר לבד להדגמה מקומית או ל-Gemini. פירוט ב-`.env.example`.

---

## הקבצים להראות בכיתה (בסדר הזה)

| קובץ | מה יש בו |
|------|----------|
| `prompt.py` | הפרומפט: Role + Guardrails + Few-Shot + הוראת JSON |
| `schema.py` | החוזה של הפלט (Pydantic). לא הקלט |
| `ask_the_model.py` | השליחה למודל: בלי מבנה / עם Analyzer + ולידציה |
| `app.py` | החלון: טקסט, תשובה, פרומפט, מה קרה |

`llm_client.py` הוא חיבור טכני (OpenAI / Gemini / הדגמה מקומית). לא חובה לפתוח בכיתה.

---

## מה להגיד בכל מצב של ה-Radio

1. **בלי מבנה** – אותה בקשה. תשובה חופשית. בפרומפט אין Role ואין JSON. ב«מה קרה» כתוב: אין ולידציה.
2. **`prompt.py`** – זה מה שהופך תשובה חופשית לחוזה: תפקיד, גבולות, דוגמאות, מבנה.
3. **עם Analyzer** – ב«תשובה» רואים JSON. ב«מה קרה» רואים: JSON תקין → ולידציה עברה.
4. **בעייתי / מניפולטיבי** – לחצי על הדוגמאות האחרות עם Analyzer. פישינג → `violation: yes`. מעטפת הסיפור → `manipulative: true`.
